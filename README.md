Exactly one word, 12 characters, describing my boss: **Micromanager**. Every task comes back with the font changed, the order shuffled, and a meeting booked to discuss why it was not done the way it was already done. The program reads the word from `entry.txt`, checks it rule by rule against the bounty gate (UTF-8, 1–30 characters, exactly one word, plain letters, no trailing space), and publishes it byte for byte to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
